# CYBER TACTICAL FPS ARENA

개포중학교 학생이 만든 브라우저 3D FPS 게임입니다. (Three.js + Tailwind CSS)

## 플레이
설치 없이 웹 브라우저(PC, 크롬 권장)에서 바로 실행됩니다.
`index.html`을 열거나 GitHub Pages 주소로 접속하세요.

## 게임 모드
- **좀비 서바이벌** — 웨이브를 버티며 크레딧을 모아 무기를 업그레이드
- **적응형 AI 1대1 대결** — AI 상대와 1:1 결투

## 맵
1. NEON CITADEL — 2층 요새와 유리 스카이브릿지
2. DESERT BAZAAR — 3층 스나이퍼 전망대와 사막 협곡

## 조작법
| 키 | 기능 |
|---|---|
| WASD | 이동 |
| 마우스 | 시점 / 좌클릭 사격 / 우클릭 무기 특수기 |
| Space ×2 | 2단 점프 |
| Shift | 조준 (6번 저격총은 스코프) |
| 1~6 / 휠 | 무기 교체 |
| R | 재장전 |
| E | 대시 |
| Q | 플래시 |
| C | 연막 |
| X | 트립마인 |
| Z | 엄폐벽 설치 |
| V | 택티컬 스프린트 |
| Ctrl | 슬라이딩 |
| F | 무기 감상 |
| B | 상점 |
| ESC | 일시정지 |
